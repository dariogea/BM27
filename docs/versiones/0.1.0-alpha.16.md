# BM27 0.1.0-alpha.16

- «Estadísticas por jugador» muestra el diferencial de marcador (+/−) durante su tiempo en pista.

Solo PC. Comprobado con eventos reales en las pruebas del reproductor y en Chromium. Instalador pendiente de prueba en Windows real.
