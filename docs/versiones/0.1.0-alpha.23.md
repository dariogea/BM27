# BM27 0.1.0-alpha.23

- **Tácticas → Dirigir partido** permite seguir la primera mitad y dar instrucciones al descanso.
- Cambia el ritmo y la presión de tu equipo para lo que queda de partido o continúa con el plan inicial.
- El marcador y las estadísticas se incorporan a la jornada cuando termina el partido. El acta detallada se puede volver a abrir durante la sesión.

Solo PC. Probado en Chromium con cuatro cuartos y dos mitades. El guardado conserva el resultado al volver a cargar. Pendiente de ejecutar el instalador en Windows real.
