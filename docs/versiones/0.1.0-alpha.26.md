# BM27 0.1.0-alpha.26

- En **Tácticas → Dirigir partido** puedes cambiar el ataque, la defensa, la cobertura del bloqueo directo y el rebote ofensivo al descanso. También puedes ajustar el ritmo y la presión.
- Las órdenes se aplican al equipo propio para el resto del encuentro. El plan de temporada se conserva para la siguiente jornada.
- La cobertura del bloqueo directo está disponible en defensa individual.

Solo PC. Pendiente de ejecutar el instalador en Windows.
