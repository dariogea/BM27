# BM27 0.1.0-alpha.4

- La partida se guarda automáticamente después de cada jornada, también al usar «Jugar y ver».
- Se conserva el guardado automático anterior para recuperar el progreso desde «Mis partidas».
- El menú principal ofrece «Continuar» con el guardado más reciente.
- La preferencia de autoguardado sigue disponible en «Partidas».

Solo PC. Clubes y jugadores generados. Las órdenes tácticas durante el partido y la
visualización del movimiento de los diez jugadores siguen pendientes.

Pruebas de esta entrega en Chromium y en la suite automatizada del proyecto. El instalador
se compila en Windows de GitHub. Su uso en un equipo Windows real sigue sin verificar.
